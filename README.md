
# 🔐 Password Strength Checker

A simple Python script that validates user-entered passwords against multiple security criteria.  
The program runs in a loop until the user provides a strong password.

---

## ✨ Features
- Ensures password length is greater than 5 characters
- Requires at least:
  - One lowercase letter
  - One uppercase letter
  - One digit
  - One special character (`!@#$%^&*+()+=<, .?/;:{}[]`)
- Provides clear feedback on missing requirements
- Exits once a strong password is entered
